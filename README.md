# 오늘의 발표자는?

인공지능과 현대사회 수업용 무작위 발표자 추첨기. 설치나 로그인 없이 버튼 또는 스페이스 키로 한 명씩 뽑습니다.

- 이름이 돌아가다 멈추는 추첨 애니메이션과 색종이 효과
- 중복 없이 추첨, 브라우저에 기록 저장, 기록 초기화
- 명단에서 오늘 제외할 사람 선택, 전체 화면, 모바일 지원
- 시스템의 움직임 줄이기 설정 반영
- 서버·분석 도구·외부 라이브러리 없이 동작. 학번을 포함하지 않습니다.

## 명단 기준

출석부 53명에서 W04–W07 발표자 16명(기록 20건, 중복 제거)을 제외한 **37명**. 사용자가 37명 사용을 확인했습니다.

표기 대응: 수문쩌 → 수몬쩌, 다와자르갈 → 다와자르갈 엥흐졸, 응웬티홍한 / 응웬티 홍한 → 응원티홍한, 친티린치 / 친띠린치 → 찐티린치, 응우엔 티 카인리 → 응우옌 티 카인 리, 짠 바어루이 → 짠 바오 루이, 응웬티 응옥한 → 응웬티응옥한. 출석부의 표기를 기준으로 문맥에 맞춰 대응했습니다. W05 밀레나 기록의 불확실성은 W04 발표 기록이 있으므로 미발표자 수에 영향을 주지 않습니다.

## 실행·게시

`index.html`을 열거나 이 폴더를 정적 웹 서버로 제공하면 됩니다. GitHub Pages는 Settings → Pages → Deploy from a branch → main / (root)로 설정합니다. 빌드 과정은 없습니다.

추첨은 Web Crypto의 난수와 거절 샘플링으로 동일한 확률을 사용합니다. 당첨자는 애니메이션 전에 기록되므로 중간에 새로고침해도 제외됩니다. 기록은 브라우저별이며 기기 사이에서 동기화되지 않습니다. 공유 컴퓨터에서 사용한 뒤에는 필요에 따라 기록을 초기화하세요.
